# XXD Panel 030｜真实自然材料编辑拼合生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前任务明确提供的这一张源照片。先锁定主体或不可拆分关系、核心比例、轮廓走势、姿态、方向、动作、功能、关系距离与颜色性格，至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的植物种类、矩形色域、配色、文字和构图。

## 用真实自然形态建立主体身份

使用清晰可辨的真实叶片、花瓣、枝条、果实、种子、草茎、树皮或枯叶重构主体。每一种材料都必须因为它原本的轮廓、叶脉、纤维、卷曲、破损、半透明、色差或不规则边缘能够承担某个源图线索而被选择。不要把植物切成精准几何形，不要先画完整主体轮廓再往里填植物，也不要用插画遮盖真实材质。

主体的主要剪影、比例、姿态、方向、动作和关系必须一眼可读。人物保留姿态与关系距离；动物保留身体节奏与头部方向；植物保留生长逻辑；建筑保留天际线与关键开口；器物和交通工具保留功能轮廓与负形；景观保留一个决定性的空间关系。每一块自然材料都服务于身份或结构，删除装饰性填充。

## 一个矩形色域，一次自然越界

建立一块简洁的矩形色域或纸面区域，色相、冷暖与明度从当前源图协调产生。边缘可由裁切或色差暗示，不刻意画出完整四边框。

主体大部分留在色域内部；只有在源图动作确实需要时，才让一小段最具方向感的部分伸出。它应像植物恰好从版面中生长出来，而不是为了表演“突破边框”刻意摆造型。色域、主体重心、不完全对称、正负形和大量留白必须组成同一套编辑秩序。

禁止多重面板、任意越界、装饰边框、完整风景、现成花环、花束、重复植物花纹、均匀散叶、贴纸、胶带和手账堆砌。

## 材料真实，黑线极少

保留自然物的摄影证据：叶脉、花瓣透光、果皮、种子尺度、草纤维、树皮裂纹、枯叶卷边、综合色差和真实叠压都要可见。阴影只用于说明材料平放在承载面上的轻微接触。

黑色线条只是例外性的辅助语言，绝不承担整体轮廓。只可用于眼睛、嘴巴、极简表情、动作暗示、必要连接、短节奏线或克制手写痕迹。禁止完整黑描边、人工剪纸形、数字绘制植物、塑料假叶、贴纸投影、戏剧化景深、光泽3D和儿童树叶贴画。

## 源图颜色与编辑文字

提取源图最有生命力和辨识度的颜色气质，再用所选自然材料本身的综合色重新转译。保留自然色差，不把所有材料统一染成一种配色。背景使用浅色或柔和综合色，矩形色域与源图协调，让天然材质成为中心。禁止固定“绿叶＋花瓣”配方，也不得沿用其他照片的植物配色。

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留。自动文案从源图可见或有依据的身份、情绪、动作、关系或隐喻中提炼一个简短标题；只有确有信息价值时增加零至两个微型注释。不得虚构植物种类、地点、日期、编号或出处。

文字使用目标文字系统中自然、轻量、精致的编辑排版，可贴近色域边缘、悬置留白，或与一根枝条、草茎、叶片方向呼应，始终低于自然材料的视觉权重。禁止常规海报大标题、伪植物标本标签、乡村手作字体、巨大文字、伪外语和后贴覆盖。无文字时不生成任何文字或伪文字。

## 模式与验收


硬性验收：至少三个源图线索与主要动作或关系；主体由形态保持完整、清楚可辨的真实自然材料承担；一块与源图协调且没有完整描边的矩形色域；主体大部分在内、只有源图需要的一小段方向性越界；大量留白与不完全对称；黑线极少且有明确功能；平面接触与叠压可信；需要文字时使用自然轻量的目标语言编辑排版；无精准植物几何形、整体描边、任意物种、现成花束或花环、贴纸、儿童树叶画、假植物、风景堆砌、照片残片、3D或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
